# Icon font licences

`indicator_icons_20.c` holds four glyphs converted with lv_font_conv 1.5.2
from CaskaydiaCove Nerd Font Propo 3.0.2:

- U+F0340 lock-open-outline, U+F04B3 sleep-off and U+F00AF bluetooth, from
  Material Design Icons by Pictogrammers (https://pictogrammers.com/library/mdi/),
  Apache License 2.0: https://www.apache.org/licenses/LICENSE-2.0
- U+F287 usb, from Font Awesome 4 by Dave Gandy, SIL Open Font License 1.1:
  https://openfontlicense.org

`nv_status_icons_20.c` (nice!view battery and connection strip) holds
Material Design Icons glyphs from the same font, Apache License 2.0:
battery-outline, battery-10 … battery-90, battery, battery-charging-outline,
battery-charging-10 … battery-charging-100, check-circle-outline and
close-circle-outline. `nv_status_digits_16.c` holds the digits 0–9 of
CaskaydiaCove (Cascadia Code), SIL Open Font License 1.1.
